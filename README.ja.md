# GoIHelper

`React`、`TypeScript`、`Electron` を使った日本語学習用のツールです。
`GoI` は日本語の `語彙（ごい）` を意味します。

## プロジェクトのセットアップ

### インストール

```bash
$ npm install
```

### 開発モード

```bash
$ npm run dev
```

### ビルド

```bash
# Windows の場合
$ npm run build:win

# macOS の場合
$ npm run build:mac

# Linux の場合
$ npm run build:linux
```
